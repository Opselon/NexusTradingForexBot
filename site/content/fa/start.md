موتور اسکالپ نکسوس یک **پلتفرم پژوهش‌محور معاملات کمی** است: یک زمان‌اجر شش‌ضلعی (Hexagonal) و رویدادمحور برای متاتریدر ۵ (بازار اصلی: طلا XAUUSD تایم M1) که داده‌های بازار، مهندسی ویژگی علّی، استنتاج مدل، سیاست استراتژی، کنترل ریسک، بازپخش (Replay)، اجرا، مشاهده‌پذیری و اعتبارسنجی بازتولیدپذیر را در یک خط لوله قابل‌ممیزی یکپارچه می‌کند.

<div class="callout"><p><strong>این وعده سود نیست.</strong> این یک پلتفرم پژوهش و مهندسی است. وضعیت‌ها بر اساس شواهد درجه‌بندی شده‌اند و نتایج منفی هم منتشر می‌شوند — از جمله رد شدن کاندیدای پژوهشی ۷۰D خودمان بر اساس شواهد Out-of-Sample. اسکالپ با اهرم ریسک مالی شدیدی دارد.</p></div>

## چه چیزی آن را متفاوت می‌کند

- **شواهد قبل از ادعا** — متریک‌های بدون شواهد به صورت `n/a` نمایش داده می‌شوند، هرگز صفر جعلی نیستند.
- **بدون آینده‌نگری (No Lookahead)** — Walk-Forward با Purge و Embargo، ویژگی‌های کاملاً علّی (INV-008).
- **برابری علّی** — معناشاسی ویژگی در زنده = بازپخش = آموزش یکسان است و با هش اسکیما محافظت می‌شود.
- **حقیقت زمان اجرا** — حقیقت بروکر بر وضعیت کهنه می‌چربد؛ گیت‌ها مرجع هستند (INV-011).
- **صفر اختیار سفارش** برای اجزای پژوهش/یادگیری (INV-002)؛ مسیر داغ تیک هرگز بلاک نمی‌شود (INV-001).
- **اعتبارسنجی قبل از ترویج** — شکست OOS یعنی REJECTED؛ ترویج صرفاً با تأیید اپراتور.

## خط لوله در یک نگاه

```text
داده بازار → ویژگی‌های علّی (۵۰D زنده / ۷۰D پژوهشی) → اعتبارسنج استنتاج
→ ScalpNet → رژیم → ماتریس سیاست SMC → موتور ریسک → OrderManager
→ بروکر (MT5 / Paper / Shadow) → حسابداری (دفتر کل غیرقابل‌تغییر)
→ حلقه تجربه و پژوهش → ترویج با تأیید اپراتور
```

## اجرا در ۶۰ ثانیه

```bash
git clone https://github.com/Opselon/NexusTradingForexBot.git
cd NexusTradingForexBot
python -m venv .venv && source .venv/bin/activate   # ویندوز: .\.venv\Scripts\Activate.ps1
pip install -e .[dev]
nexus doctor          # عیب‌یابی فقط‌خواندنی
nexus start           # حالت PAPER (پیش‌فرض امن) → http://127.0.0.1:8080
```

کاربران عادی می‌توانند نسخه بسته‌بندی‌شده ویندوز را (بدون نیاز به پایتون) از GitHub Releases دانلود کنند یا از نصب‌کننده PowerShell استفاده کنند. راهنمای کامل: [نصب](https://github.com/Opselon/NexusTradingForexBot/blob/main/docs/getting-started/installation.md).

# موتور اسکالپ نکسوس — مستندات

**پلتفرم معاملات کمّی مبتنی بر پژوهش** — یک موتور اسکالپ شش‌ضلعی و رویدادمحور
برای متاتریدر ۵ (بازار اصلی: XAUUSD در تایم M1)، ساخته‌شده حول مهندسی ویژگی
علّی، حکومت داده‌محور مدل‌ها (Model Factory)، ابزار پژوهش قطعی، و مشاهده‌پذیری
جنگل‌بانی‌شده (forensic).

> [!IMPORTANT]
> این مستندات یک **پلتفرم پژوهش و مهندسی** را توصیف می‌کند. این متن توصیه
> سرمایه‌گذاری نیست و هیچ‌جای آن وعده سودآوری نیست. اسکالپ با اهرم ریسک مالی
> شدیدی دارد. برای تفکیک «تایید‌شده / آزمایشی / برنامه‌ریزی‌شده»
> [وضعیت پروژه](../project/status.md) را ببینید.

## شروع سریع

```bash
nexus doctor          # عیب‌یابی کامل (فقط-خواندنی)
nexus start           # حالت PAPER به‌صورت پیش‌فرض — هرگز بدون تأیید صریح، LIVE نمی‌شود
nexus start --mode shadow   # دیتای زنده، بدون هیچ اختیار سفارش
```

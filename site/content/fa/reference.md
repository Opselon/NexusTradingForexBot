## پرسش‌های متداول

**نکسوس چیست؟**
یک پلتفرم پژوهش‌محور معاملات کمی: موتور اسکالپ شش‌ضلعی و رویدادمحور برای متاتریدر ۵ (XAUUSD M1) با ویژگی‌های علّی، مدل‌های عمیق، ریسک ثابت‌شده، پژوهش قطعی و مشاهده‌پذیری فارنزیک.

**آیا این یک ربات معاملاتی زنده است؟**
می‌تواند معاملات زنده اجرا کند — اما پیش‌فرض PAPER است، SHADOW صفر اختیار سفارش دارد، LIVE نیازمند تأیید صریح تعاملی است و مخزن کاندیداهای ردشده را منتشر می‌کند. این پلتفرمی پژوهشی با زمان‌اجر است، نه دستگاه پول.

**بدون MT5 می‌توانم اجرا کنم؟**
بله — حالت PAPER و کل مجموعه تست بدون بروکر اجرا می‌شوند؛ Docker هم به‌صورت پیش‌فرض در PAPER کار می‌کند.

**۷۰D چیست؟**
قرارداد مرجع ویژگی پژوهشی (۵۰ پایه + ۱۰ اخبار + ۱۰ نقدینگی). زنده نیست — قرارداد زنده ۵۰D است. کاندیدای ۷۰D تاکنون بر اساس شواهد OOS رد شده است.

**نشتی (Lookahead) چگونه پیشگیری می‌شود؟**
Walk-Forward پاکسازی‌شده و تحریم‌شده، ویژگی‌های کاملاً علّی، مدیریت REPLACE+ALIGN تاریخچه، تست‌های بازپخش بی‌دقیق، و ثبت مقادیر مؤثر purge/embargo در هر اجرا.

**مدل‌ها چگونه شناسایی می‌شوند؟**
مانیفست‌های مصنوع: شناسه دیتاست، هش اسکیما، هویت اسکیلر، کامیت گیت — در هر اتصال توسط گیت بارگذاری ۱۰-گانه اعتبارسنجی می‌شود.

**بازپخش چه تفاوتی با بک‌تست دارد؟**
بک‌تست استراتژی را روی تاریخ نمره می‌دهد؛ بازپخش ثابت می‌کند همان مسیر کدِ زنده روی تاریخ رفتار یکسانی دارد (بی‌دقیق نسبت به دیتاست).

**سودآور است؟**
هیچ ادعایی نمی‌شود — این همان نکته است. از شواهد منتشرشده قضاوت کنید، از جمله نتایج منفی.

## واژه‌نامه (گزیده)

| اصطلاح | معنا |
| :--- | :--- |
| 50D / scalp_v1 | قرارداد فعال زنده ۵۰-بعدی ویژگی‌های علّی |
| 70D / scalp_v3 | قرارداد مرجع پژوهش: پایه ۰..۴۹ + اخبار ۵۰..۵۹ + نقدینگی ۶۰..۶۹ |
| هش اسکیما | SHA-256 روی JSON رسمی ویژگی‌ها — جابه‌جایی ترتیب مدل را باطل می‌کند |
| Shadow | زمان‌اجر داده زنده، `simulated=True`، صفر اختیار سفارش |
| بازپخش | اجرای دوباره منطق موتور روی تاریخ؛ باید بی‌دقیق نسبت به دیتاست باشد |
| گیت OOS | گیت سخت خارج از نمونه؛ شکست یعنی REJECTED |
| Champion / Challenger | مدل تولید در برابر کاندیدا؛ ترویج با تأیید اپراتور |
| گیت استقرار | حکم فارنزیک پیش از انتشار: PASS / REVIEW / BLOCK |
| منشأ | زنجیره هویت یک مصنوع؛ `NOT_RECORDED` وقتی صادقانه نامعلوم است |
| INV-NNN / BUG-NNN / CHG-NNNN | ناورداها / دفتر باگ فارنزیک / رجیستری تغییرات |

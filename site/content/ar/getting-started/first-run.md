# التشغيل الأول — السلامة (تجريبي → SHADOW → LIVE)

ينفّذ هذا المحرك أوامر على وسيط حقيقي. التوجيه الرسمي للمستودع سلّم صارم — لا تتجاوز أي خطوة.

| الخطوة | الإجراء | السبب |
| :--- | :--- | :--- |
| ١️⃣ | سجّل الدخول إلى **حساب تجريبي** في MT5 (`File → Open an Account → Practice/Demo`) وأكّد رقم/اسم الحساب قبل أي شيء | الحساب الحي والتجريبي يبدوان متطابقين في نافذة دخول MT5 |
| ٢️⃣ | في MT5: `Tools → Options → Expert Advisors → فعّل "Allow Algo Trading"` | بدونه تُرفض الأوامر |
| ٣️⃣ | انسخ `configs/live.yaml` إلى `configs/demo.yaml`؛ أدخل بيانات الحساب التجريبي؛ أكّد `risk.max_concurrent_positions: 1` و `risk.risk_per_trade_pct` (مثل 0.5) و `risk.max_account_drawdown_pct` | لا تلمس إعدادًا حيًا بينما المال الحقيقي في المتناول |
| ٤️⃣ | شغّل **SHADOW** أولًا (`nexus start --mode shadow`) لعدة أيام؛ راقب لوحة التحكم وتقارير تيليجرام | يثبت النموذج والإشارات والبوابات قبل أي تنفيذ |
| ٥️⃣ | شغّل مجموعة الاختبارات أسبوعيًا (`pytest tests/unit tests/integration`) | يكتشف الانحدارات قبل وصولها إلى حساب حي |
| ٦️⃣ | عندها فقط فكّر في **LIVE** برصيد صغير تتحمل خسارته؛ `risk_per_trade_pct: 0.25` أو أقل | السكالب بالرافعة على XAUUSD يحمل مخاطر مالية بالغة |

## صمام أمان هوية الحساب

يرفض المحوّل الحي الاتصال بمرحّل مسجَّل بحساب مختلف عن المضبوط (BUG-142): فحص هوية الحساب مفروض عند الاتصال، لا بالاتفاق.

## ثوابت السلامة (مفروضة من المحرك)

- `nexus start` **لا** يكون LIVE افتراضيًا أبدًا — الافتراضي PAPER؛ وLIVE يتطلب تأكيدًا تفاعليًا صريحًا.
- تشغيلات SHADOW تحمل `simulated=True` و**صفر صلاحية أوامر**: لا يمكن وضع أو تعديل أو إغلاق أي أمر.
- عمّالات البحث/الاستراتيجية/الأخبار لا تحمل صلاحية أوامر أو مقبض مخاطر أبدًا.
- محرك المخاطر هو المرجع لحدود التحجيم: قيد الهامش (≤ 20% من الهامش الحر)، سقوف الفئات، سقف مركز واحد، `HARD_MAX_LOTS = 10.0`، `MAX_TOTAL_EXPOSURE = 1`.
- قاطع الدائرة → SAFE_MODE بعد الرفضات المتكررة؛ مثبّط تكرار الأوامر؛ مفتاح إيقاف من اللوحة/CLI.
- بوابة الفحص المسبق تتحكم بكل إقلاع: غياب مرحّل MT5 أو إعداد غير صالح أو منصة غير مدعومة ⇒ يرفض المحرك البدء.
- ترقية النموذج بقرار المشغّل حصريًا؛ المرشحون لا يرقّون أنفسهم؛ SHADOW لا يغيّر التنفيذ أبدًا.

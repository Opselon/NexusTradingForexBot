محرك Nexus Scalp هو **منصة تداول كمي قائمة على البحث**: نظام تشغيل سداسي (Hexagonal) مدفوع بالأحداث لميتاتريدر 5 (السوق الأساسي: الذهب XAUUSD على فريم M1) يربط بيانات السوق، وهندسة الخصائص السببية، واستدلال النماذج، وسياسة الاستراتيجية، وضبط المخاطر، وإعادة التشغيل (Replay)، والتنفيذ، وقابلية المراقبة، والتحقق القابل لإعادة الإنتاج في خط أنابيب واحد قابل للتدقيق.

<div class="callout"><p><strong>ليس وعدًا بالربح.</strong> هذه منصة بحث وهندسة. الحالات تُدرَّج وفق الأدلة، والنتائج السلبية تُنشر — بما في ذلك رفض مرشحنا البحثي 70D استنادًا إلى أدلة خارج العينة. التداول بالرافعة على أطراف قصيرة يحمل مخاطر مالية بالغة.</p></div>

## ما الذي يجعله مختلفًا

- **الأدلة قبل الادعاءات** — المقاييس بلا أدلة تظهر `n/a`، وليس أصفارًا مزيفة أبدًا.
- **بلا نظرة مستقبلية** — Walk-Forward مع Purge و Embargo، وخصائص سببية صارمة (INV-008).
- **التكافؤ السببي** — دلالات متطابقة بين الحي = إعادة التشغيل = التدريب، محمية ببصمة المخطط.
- **حقيقة وقت التشغيل** — حقيقة الوسيط تتفوق على الحالة القديمة؛ البوابات هي المرجع (INV-011).
- **صفر صلاحية أوامر** لمكونات البحث/التعلم (INV-002)؛ مسار التيك الساخن لا يُسد أبدًا (INV-001).
- **التحقق قبل الترقية** — فشل OOS يعني REJECTED؛ الترقية بقرار المشغّل حصرًا.

## خط الأنابيب في لمحة

```text
بيانات السوق → خصائص سببية (50D حي / 70D بحثي) → مدقق الاستدلال
→ ScalpNet → النظام السعري → مصفوفة سياسات SMC → محرك المخاطر → OrderManager
→ الوسيط (MT5 / paper / shadow) → المحاسبة (سجل غير قابل للتغيير)
→ حلقة الخبرة والبحث → ترقية بقرار المشغّل
```

## شغّله في 60 ثانية

```bash
git clone https://github.com/Opselon/NexusTradingForexBot.git
cd NexusTradingForexBot
python -m venv .venv && source .venv/bin/activate   # ويندوز: .\.venv\Scripts\Activate.ps1
pip install -e .[dev]
nexus doctor          # تشخيص للقراءة فقط
nexus start           # وضع PAPER (الافتراضي الآمن) → http://127.0.0.1:8080
```

يمكن للمستخدمين النهائيين تنزيل إصدار ويندوز المعبأ (دون بايثون) من GitHub Releases أو استخدام مثبّت PowerShell. التعليمات الكاملة: [التثبيت](https://github.com/Opselon/NexusTradingForexBot/blob/main/docs/getting-started/installation.md).

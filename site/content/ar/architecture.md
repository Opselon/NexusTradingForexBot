NSE بنيته **سداسية (Ports-and-Adapters) ومدفوعة بالأحداث**: منصات الوسطاء والنماذج ومحوّلات الشبكة خلف عقود المنافذ (`IMT5Port`، `IGatewayPort`)؛ النطاق لا يعرف أبدًا أي وسيط متصل.

```text
بيانات السوق (MT5 / ZMQ / paper)
  → خصائص سببية — قاعدة 50D (scalp_v1) · تجميع 70D خاضع للحوكمة
  → مدقق الاستدلال — بصمة المخطط · بُعد المقياس · الحدود (رفض صاخب)
  → ScalpNet (TCN + انتباه ذاتي) — 4 logits → بوابة الثقة
  → حارس النظام السعري → مصفوفة سياسات SMC (~30 قاعدة)
  → محرك المخاطر (حجم كِيلي · هامش ≤20% · سقوف الفئات · HARD_MAX_LOTS=10)
  → OrderManager (موجّه 60-سيناريو · 11 حالة مركز · تفكيك ذري)
  → محوّل IMT5Port → MT5 / paper / shadow (صفر صلاحية أوامر)
  → المحاسبة (SQLite WAL غير قابل للتغيير) → الخبرة والتشريح
  → قابلية المراقبة (سجلات · حوادث · جنائي) + مركز التحكم (REST/SSE/WS)
```

## الطبقات

| الطبقة | المسؤولية | الحد الصارم |
| :--- | :--- | :--- |
| النطاق | عقود Pydantic مجمّدة | لا تُبدَّل أبدًا |
| المنافذ/المحوّلات | IPC Win32 لميتاتريدر · ZMQ · paper · مستودع SQLite WAL | لا قاعدة بيانات متزامنة على المسار الساخن |
| الخصائص | المحرك السببي 50D/70D · سجل وبصمة المخطط | الترتيب عقد |
| النماذج/التدريب | ScalpNet · Walk-Forward منقّى · حاجز ثلاثي | لا نظرة مستقبلية |
| الإشارات | السياسة · مصفوفة قواعد SMC | لا صلاحية أوامر |
| المخاطر / التنفيذ | حدود الحجم · إرسال 60-سيناريو | قيود مرجعية |
| حلقة الذكاء | خبرة · بحث · ظل · حوكمة | صفر صلاحية أوامر |
| قابلية المراقبة | سجلات · حوادث · جنائي | تشخيصي فقط |

## الخصائص الرئيسية

- **INV-001** — صفر قاعدة بيانات/تدريب/شبكة متزامنة على مسار التيك.
- **INV-002** — مكونات التعلم لا تستطيع فعليًا وضع أوامر.
- **INV-008** — لا نظرة مستقبلية؛ السيولة سببية صارمة.
- **INV-011** — حقيقة الوسيط تتفوق عند مطابقة المراكز.
- حزم النماذج تمر بـ**بوابة التحميل ذات 10 بوابات** عند كل ربط؛ عدم تطابق البُعد/البصمة يحجب بصوت عالٍ مع رمز تشخيصي، ولا صامت أبدًا.

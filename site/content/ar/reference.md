## الأسئلة الشائعة

**ما هو Nexus؟**
منصة تداول كمي قائمة على البحث: محرك تداول سداسي مدفوع بالأحداث لميتاتريدر 5 (XAUUSD M1) بخصائص سببية ونماذج عميقة ومخاطر ثابتة وبحث حتمي وقابلية مراقبة جنائية.

**هل هذا روبوت تداول حي؟**
يمكنه تنفيذ صفقات حية — لكن PAPER هو الافتراضي، وSHADOW بلا صلاحية أوامر، وLIVE يتطلب تأكيدًا تفاعليًا صريحًا، والمستودع ينشر المرشحين المرفوضين. إنها منصة بحث بنظام تشغيل، وليست آلة نقود.

**هل أستطيع تشغيله بدون MT5؟**
نعم — وضع PAPER ومجموعة الاختبارات كاملة تعملان بدون وسيط؛ وDocker يعمل جاهزًا بوضع PAPER.

**ما هو 70D؟**
عقد الخصائص البحثي المعياري (50 قاعدة + 10 أخبار + 10 سيولة). ليس حيًا — العقد الحي هو 50D. مرشح 70D مرفوض حتى الآن وفق أدلة OOS.

**كيف يُمنع التسريب؟**
Walk-Forward منقّى ومحجور، خصائص سببية صارمة، معالجة REPLACE+ALIGN للتاريخ، اختبارات إعادة تشغيل مطابقة بت-بت، وتسجيل قيم التطهير/الحجر الفعلية لكل تشغيل.

**كيف تُعرَّف النماذج؟**
بيانات المخرجات: معرّف مجموعة البيانات، بصمة المخطط، هوية المقياس، کوميت Git — تُحقق ببوابة التحميل ذات 10 بوابات عند كل ربط.

**ما الفرق بين إعادة التشغيل والاختبار الرجعي؟**
الاختبار الرجعي يقيّم استراتيجية على التاريخ؛ إعادة التشغيل تثبت أن *مسار الكود نفسه* الذي سيعمل حيًا يتطابق سلوكيًا على التاريخ (مطابقة بت-بت مع مجموعة البيانات).

**هل هو رابح؟**
لا يُقدَّم أي ادعاء — وهذه هي النقطة. احكم من الأدلة المنشورة، بمن فيها النتائج السلبية.

## المسرد (مختارات)

| المصطلح | المعنى |
| :--- | :--- |
| 50D / scalp_v1 | عقد الخصائص السببية الحي النشط بـ50 بعدًا |
| 70D / scalp_v3 | العقد البحثي المعياري: القاعدة 0..49 + الأخبار 50..59 + السيولة 60..69 |
| بصمة المخطط | SHA-256 على JSON الخصائص المعياري — إعادة الترتيب تُبطل النماذج |
| Shadow | وقت تشغيل ببيانات حية، `simulated=True`، صفر صلاحية أوامر |
| إعادة التشغيل | إعادة تنفيذ منطق المحرك على التاريخ؛ يجب أن تطابق مجموعة البيانات بت-بت |
| بوابة OOS | بوابة صارمة خارج العينة؛ الفشل ⇒ REJECTED |
| Champion / Challenger | نموذج الإنتاج مقابل المرشح؛ الترقية بقرار المشغّل |
| بوابة النشر | حكم جنائي قبل الإصدار: PASS / REVIEW / BLOCK |
| المصدر | سلسلة هوية المخرج؛ `NOT_RECORDED` عند المجهول الصادق |
| INV-NNN / BUG-NNN / CHG-NNNN | الثوابت / سجل الأخطاء الجنائي / سجل التغييرات |

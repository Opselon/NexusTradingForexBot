البحث موجود لإنتاج **أدلة قابلة للتكذيب**. المرشح الذي لا يمكن تكذيبه (بلا OOS، بلا تكافؤ إعادة تشغيل، بلا مصدر) لا يلمس مسار الحي أبدًا.

## السلسلة

```text
بيانات (مجموعات ببصمة) → خصائص (عقد سببي) → وسم (حاجز ثلاثي)
→ تدريب (ببذرة، حتمي) → اختبار رجعي (واعٍ بالاحتكاك)
→ Walk-Forward (تطهير + حجر) → بوابة OOS (فشل ⇒ REJECTED)
→ اختبار المتانة → مضاد للواقع → السجل → الظل → ترقية المشغّل
```

## المكونات

- **مجموعات البيانات** — غير قابلة للتغيير، ببصمة، بمصدر متتبع؛ مجموعات التيك تُقتنى عبر سطح المحوّل المعتمد وتبقى دون اتصال بعد الاقتناء.
- **الاختبارات الرجعية** — حتمية؛ فروق الأسعار/الانزلاق/زمن التأخير تُنمذج.
- **إعادة التشغيل** — مطابقة بت-بت مع مجموعة البيانات (اختبارات مانعة للتسريب)؛ إعادة التشغيل المتدفقة تشغّل المحرك المشترك على ساعة منطقية بتعبئات محاكاة ومحظور بموجب اختبار استدعاء `order_send`.
- **المضاد للواقع (CHG-0041)** — مشي قرارات NO_TRADE بتعبئات افتراضية: 2095 قرارًا، 476 مغطى؛ أثبتت طبقة CONFIDENCE_GATE كمرشّح صحيح (متوسط R يساوي −0.506)؛ ووُسمت طبقة SUPPORT-margin لمراجعة السياسة.

## المصدر والحتمية

كل تشغيل يسجل معرّف مجموعة البيانات، وبصمة المخطط، وکوميت Git، وقيم التطهير/الحجر الفعلية (انحدار BUG-183). يُكتب `NOT_RECORDED` عندما يكون المجهول حقيقةً — ولا يُستدرك لاحقًا أبدًا. الاختبارات الأمامية بالالتقاط المجمد تعيد التحقق من التجميد بعد التشغيل.

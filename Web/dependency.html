How to read this graph
  • What is this? A canonical dependency model built from real AST analysis of the NSE repository — imports, constructor injection, Protocol/ABC implementation, dependency registration, and architecture layers.
  • How was it generated? AST parse of every src/nexus_scalp/*.py — no runtime boot, no engine start. Each edge carries file:line evidence and a confidence.
  • How trustworthy is an edge? Confidence: 1.00 proven-by-syntax, 0.90+ strong inference, 0.70+ supported, <0.40 heuristic.
  • Why does a dependency exist? Click a node → inspector shows each edge with its evidence file:line.
  • What does a node affect? Use Impact to see direct/transitive dependents, tests, and API/runtime impact.
  • Where is a binding registered? REGISTERS edges point from the registration call site to the registered class.
  • What can break if this changes? Impact panel lists inferred test/runtime breakage (inferred, not certain).

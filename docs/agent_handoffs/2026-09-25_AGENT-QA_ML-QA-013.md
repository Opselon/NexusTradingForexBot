## What changed

`tests/unit/test_bug285_overflow_drain.py` is a push-gate module
(`tests/critical_suite.txt` entry). The ML-QA-003 census counted 3 live
non-determinism sources in it: two `time.monotonic()` reads plus one
hand-written stamp derived from the same clock.

The production throttle
(`AuditRepository._drain_financial_overflow_due`, audit_repository.py:3243)
compares a `time.monotonic()` read against the stored stamp over
`OVERFLOW_RECOVERY_INTERVAL_SEC` (60s). The cadence tests simulated the
interval passing by *assigning their own stamps* from that same clock
(`repo._last_overflow_drain = time.monotonic()` and
`= time.monotonic() - (INTERVAL + 1)`), so which side of the strict `<`
boundary a test sat on was a property of the host's monotonic domain (uptime),
not of the code under test — and the two boundary edges were indistinguishable.

Remediation:

1. **Production seam (additive, 2 lines)** — the drain takes an optional
   `now: float | None = None`; `now is None` still reads `time.monotonic()`.
   The same idiom the repo already uses in `storage/runtime.py::is_due`. The
   single production caller (audit worker idle pass) is unchanged and passes no
   argument — pinned by a battery rule, so the runtime path is
   byte-for-byte identical.
2. **One deterministic monotonic-domain clock** (`_MonotonicClock` + the
   `drain_clock` fixture) drives the cadence tests through that argument:
   `advance(dt)` instead of sleeping or hand-stamping. Both edges of the strict
   `<` boundary are now reproducible to the nanosecond — one tick SHORT of the
   interval stays throttled, exactly AT the interval is DUE (equality is not
   `< interval`).
3. The tests no longer write `_last_overflow_drain` at all; the production
   method owns that write from the injected value.
4. New contract battery
   `tests/unit/test_ml_qa_013_overflow_drain_clock_determinism.py` (17 tests).

No contract weakened: all 12 durable tests preserved with names + hard asserts
byte-identical. The module went 14 → 16 tests (one boundary-edge test added,
none removed or renamed).

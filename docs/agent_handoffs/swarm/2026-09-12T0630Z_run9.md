## Part 2 — BUG-261 FIXED (role 9: observability-surface clock domain)

### Defect
`emit_terminal_pending_outcome` (terminal_outcome.py:96) stamped
`outcome_timestamp` with host wall clock. The ledger causality guard
(`record_terminal_outcome`, ledger.py:323: `outcome_timestamp >=
decision_timestamp`, where decision_timestamp is tick/broker-domain
`proposal.generated_at`) REFUSES a wall stamp when the host runs BEHIND the
broker — hanging the decision as MISSING_OUTCOME forever. Same G3/BUG-259/
BUG-260 defect class, on the observability (experience-ledger) surface.
Observed production skew was host-AHEAD (Age -10781.6s, passes causality but
future-dates rows); host-behind is the data-loss direction.

### Scope (evidence)
- 7 live call sites, NONE passed tick-domain time (verified by grep):
  dispatch.py ×6 (262/279/336/377/394/475/550), tick_pipeline.py ×1 (165),
  pending_orders.py `emit_terminal_for_pending` (447).
- `OrderIntentStore.resolve()` (order_write.py:179): ZERO production callers
  (only tests/unit/test_order_write_uncertainty.py) — dormant; hardened
  signature-only.
- Recovery sweep `_emit_terminal` (outcome_recovery_sweep.py:630): tick-less
  (startup/offline) with `decision_timestamp` already SELECTed (line 192).

### Fix (all additive, no signature breaks; existing callers unaffected)
1. `terminal_outcome.py`: `outcome_timestamp=None` -> ledger lookup of the
   decision + `max(wall, decision_ts)` clamp, failure-isolated (ledger error ->
   legacy wall clock). Docstring contract added.
2. `dispatch.py` ×6 (7th site counted at 475+550 as market+pending refuse):
   `outcome_timestamp=getattr(decision, "generated_at", None)` — tick-domain,
   zero extra I/O, None-safe.
3. `tick_pipeline.py:165`: `outcome_timestamp=tick.timestamp` (in scope).
4. `pending_orders.py`: `emit_terminal_for_pending(..., at=None)` +
   `cancel_pending_order_verified(..., at=None)` +
   `cancel_pending_order_with_retry(..., at=None)`; manage-loop site passes
   `at=current_tick.timestamp`. `order_manager.py` delegates passthrough.
5. `outcome_recovery_sweep.py` `_emit_terminal`: parses the already-selected
   `dec["decision_timestamp"]`, passes as outcome_timestamp (None on parse
   failure -> clamp fallback).
6. `order_write.py` `resolve()`: new optional `resolved_at: datetime|None`
   (isoformat bridge preserves the `str|None` field type).

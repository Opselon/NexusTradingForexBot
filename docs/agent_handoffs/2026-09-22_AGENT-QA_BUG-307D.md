## Summary

Run 29's deliverable (PR #349, BUG-307C) landed to main while this cycle was
triaging it. Main's OS Matrix lane was red at both the pre-#349 sha (73f5eaf4)
and the post-#349 sha (cb51ed56) — so the red was NOT caused by #349. It was a
pre-existing Windows-only defect shipped by #347 (ML-ARCH-001) that only became
visible once ML-CI-002/#347 registered the file in `tests/critical_suite.txt`.
This cycle root-caused it and fixed it.

## Bug 1 of 2 — the probe (3 failures, one root cause)

`scripts/audit/audit_legacy4_surface.py:79` used
`rel = str(path.relative_to(root))`. `Path.relative_to` joins with `os.sep`,
which is `\` on Windows. The probe's `_PATH_CLASS` table and every pinned
assertion compare forward-slash substrings, so on Windows no prefix matched and
`_classify` returned `OTHER` for every site. One line explains all three
failures:

| CI failure | Windows symptom |
|---|---|
| `test_probe_classifies_production_serving_literal` | `assert 0 == 1` (serving literal → OTHER) |
| `test_probe_reports_function_context` | `assert 'OTHER' == 'SMOKE'` |
| `test_head_legacy4_sites_are_non_serving` | message contains `src\nexus_scalp\smoke\runner.py` |

The verdict on main stayed `LEGACY-4-DEAD-WEIGHT` (correct) because the serving
path has no 4-wide literal — so the bug corrupted the *evidence*, not the
conclusion. It was silent on the evidence for an operator decision (DEC-0010).

## Bug 2 of 2 — one test (pre-existing, #250 era)

`test_slot_lock_excludes_concurrent_process` spawns a holder child running
`import fcntl; fcntl.flock(...)`. `fcntl` is Unix-only: on Windows the child
dies on import, writes nothing, and the assert reads `'' == 'LOCKED'`. The
production lock (`official_install.model_slot_lock`) IS cross-platform (win32
`msvcrt.locking` / posix `fcntl.flock`); only the test's helper child is
Unix-only.

## Fix

1. `scripts/audit/audit_legacy4_surface.py`: `_rel_posix(path, root)` →
   `path.relative_to(root).as_posix()`; `scan_literals` uses it. Report paths
   are now byte-identical between matrix legs (stable pinned evidence).
   `_classify` unchanged — it was correct, its input was not.
2. `tests/integration/test_official_model_tamper_proofing.py`: `skipif` on the
   one test whose child needs `fcntl`. The win32 lock path stays covered by the
   file's other slot-lock tests.
3. `tests/unit/test_audit_legacy4_surface.py`: new
   `test_probe_classifies_subsystem_independently_of_os_sep`.
